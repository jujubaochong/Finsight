## 一句话描述

> 让个人投资者输入 A 股代码，就能在 30 秒内获得一份 AI 生成的结构化个股分析报告——替代在 3 个 App 之间来回查找的碎片化体验。

---

## 问题洞察（为什么做）

个人投资者研究一只股票时，当前工具链的断裂点：

- **同花顺**：给你看数据，但不解读数据（毛利率 35%，不告诉你这在行业里算什么水平）
- **东方财富 F10**：信息全面但像黄页，没有分析路径引导
- **雪球**：信噪比太低，90% 是情绪输出
- **巨潮资讯**：原始 PDF，200 页年报不可能逐页看

**核心发现**：所有工具都在"给你看数据"，没人"帮你理解数据"。

---

## 解决方案（做了什么）

| 功能 | 说明 |
|------|------|
| **智能搜索** | 支持代码/名称/拼音/首字母，输入即搜，直接跳转详情 |
| **AI 快速分析** | 10 秒内输出：一句话总结 + 3 个亮点 + 3 个风险 + 核心指标解读 |
| **财务可视化** | 近 8 季度收入/利润趋势图、ROE 趋势图，年度/季度切换 |
| **AI 深度研报** | 点击"生成完整报告"，异步生成 7 章结构化研报（30 秒-2 分钟） |
| **自选股管理** | 添加关注股票，系统自动监控公告异动（减持、问询函、业绩预告等） |
| **报告导出** | 支持 Word/PDF 导出，作为投资笔记归档 |

**核心差异**：从"问答式数据查询"升级为"结构化报告生成"——输入代码 → 输出研报，而非输入问题 → 输出答案。

---

## 关键设计决策（为什么这样设计）

| 决策 | 选择 | 理由 |
|------|------|------|
| 不做实时行情/K线 | 明确放弃 | 行情需交易所授权，成本高且不形成差异化；用户手机已有同花顺 |
| 不做交易下单 | 明确放弃 | 合规红线（持牌投顾才能给建议），且与竞品正面竞争无意义 |
| 不做社区/UGC | 明确放弃 | 雪球网络效应已形成，冷启动不可能；AI 分析本身就是内容 |
| 快速分析 vs 深度分析分层 | 分层设计 | 首次了解只需 10 秒快速判断；确认有兴趣后再等 2 分钟深度报告 |
| 90% DeepSeek + 10% Claude | 混合模型 | 成本可控（$0.27/1M tokens），同时保证复杂推理质量 |
| 链式调用而非端到端 | 分步处理 | 单次 Token 可控、单步失败可重试、可插入人工审核 |

## 竞品定位与差异化

```

  ├─ 轻量 AI 问答（同花顺/东财/雪球）—— 数据播报，无深度
  ├─ 专业终端（Wind）—— 数据极深，但 ¥3-8万/年，难用
```

## 我的核心贡献（产品视角）

1. **需求洞察**：通过 5+ 次真实用户观察，定义了"信息碎片化→看不懂→找不到靠谱分析→每次研究像第一次"的痛点链条
2. **竞品破局**：识别出所有竞品在"报告生成"和"主动风险发现"两个维度的空白，确定为差异化定位
3. **AI 产品化设计**：设计链式调用架构，编写 3 套 System Prompt，制定 5 维度质量评估标准（准确率/幻觉率/深度/可读性/价值）
4. **范围控制**：明确 6 项"不做"（交易、行情、社区、K线、港美股、投资建议），确保 MVP 单人可交付
5. **数据驱动**：定义北极星指标（WAU）、转化漏斗、4 组 A/B 实验假设

## 技术实现（执行视角）

| 模块 | 实现方式 |
|------|---------|
| 数据管线 | AkShare Python SDK 定时拉取，try-catch + 重试 + 缓存 + 降级 |
| AI 分析 | FastAPI 后端调用 DeepSeek API，链式调用（4 并行 + 1 组装） |
| 报告生成 | Celery 异步任务，前端轮询进度，支持 Word/PDF 导出 |
| 前端 | React + Tailwind，Recharts 图表渲染，Markdown 报告展示 |

## 关键风险与应对

| 风险 | 概率 | 应对 |
|------|:----:|------|
| AkShare 接口不稳定 | 中 | 准备 Tushare 备用源；核心接口加缓存和降级 |
| AI 分析质量不达预期 | 中 | 规则引擎保底；Prompt 迭代优化；标注"仅供参考" |
| 竞品（同花顺）上线类似功能 | 中 | 差异化在"分析深度"——产品认知差，非技术差 |
| 数据合规风险 | 低 | 仅展示摘要，标注来源；正式商业化前法律咨询 |
