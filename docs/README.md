---

## 3 秒了解这个项目

FinSight 是一款面向个人投资者的 **AI 智能投研助手**。用户输入 A 股代码，即可在 30 秒内获得一份结构化的 AI 分析报告——包含财务趋势解读、主动风险识别、公告摘要和机构观点整合，替代在 3 个 App 之间来回查找的碎片化体验。

**核心差异化**：从"给你看数据"到"帮你理解数据"——不是数据终端，而是分析助手。

## 我的角色与贡献

| 维度 | 我的工作内容 |
|------|------------|
| **产品策略** | 定义产品愿景、目标用户分层、MVP 范围边界（明确 6 项不做） |
| **竞品研究** | 深度使用同花顺 AI 问财、东方财富妙想、雪球 AI 等 4 款产品，产出竞品矩阵与差异化定位 |
| **用户研究** | 基于真实观察与访谈，构建 3 类用户画像（张弛/林薇/赵明远），定义核心场景与 MoSCoW 优先级 |
| **PRD 编写** | 输出完整功能 PRD（搜索聚合、AI 分析引擎、报告生成、自选股管理），含流程图、边界情况、设计决策 Q&A |
| **AI 策略** | 设计链式调用架构（90% DeepSeek + 10% Claude 兜底），编写 System Prompt，制定 5 维度质量评估体系 |
| **原型设计** | 用 ASCII 线框 + 文字描述输出 4 个核心页面的信息架构与交互流程 |
| **指标体系** | 定义北极星指标（WAU）、核心转化漏斗、A/B 实验方案 |
| **路线图** | 制定 M1-M6 三阶段路线图，明确 MVP 范围与关键风险应对 |
| **技术实现** | 独立开发 MVP（FastAPI + React + DeepSeek API + AkShare 数据源）|
